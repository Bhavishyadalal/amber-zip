Install Amber Studio without the confusion

The normal Amber Studio setup is intentionally simple. For the full virtual-mic experience, follow the optional VB-CABLE setup below.

  1. Download Amber StudioUse the Amber Studio download button on this page and keep Amber Studio in its own folder.
  2. Launch Amber StudioOpen Amber Studio.exe. Your downloads, soundboard and settings are kept with the app folder.
  3. Start with BrowsePaste a video, Short, playlist, album or channel link, or unlock search in Setup.

Virtual mic setup — VB-CABLE

Amber Studio can send your voice + song + soundboard mix to a game's microphone input. VB-CABLE is the bridge between Amber Studio and the game.

01 · Download

Get VB-CABLE from VB-Audio

Use the official Windows package. The official page lists VBCABLE_Driver_Pack45.zip and supports Windows 32/64-bit plus Arm64.

Download VB-CABLE ZIPOfficial VB-Audio page
02 · Install

Extract → Run as administrator → Restart

  1. Extract the ZIP completely to a normal folder.
  2. On 64-bit Windows, right-click VBCABLE_Setup_x64.exe → Run as administrator.
  3. Finish the installer.
  4. Restart Windows after installation.

Do not run the setup program directly from inside the ZIP.

03 · Connect Amber Studio

Amber Studio → Mic → Virtual mic

  1. Open Amber Studio and go to Mic.
  2. Enable the virtual mic. Amber Studio should detect CABLE Input as its virtual output device.
  3. Allow microphone/device access if Windows asks.
  4. Use the Mic controls to choose whether the game receives your voice, the song, and soundboard sounds.
04 · Connect your game

Game microphone = CABLE Output

In the game's voice/microphone settings, select CABLE Output as the microphone. Think of the names as the two ends of the same cable:

Amber Studio mixCABLE Input→CABLE OutputGame mic

Good to know

Where are my files saved?

Beside Amber Studio.exe. Give Amber Studio its own folder, such as Desktop\Amber Studio, and your downloads, queue and settings all stay inside it.

Do I need to install anything?

Amber Studio itself is distributed as an executable/installer build. For the virtual-mic and soundboard workflow, install VB-CABLE separately and restart Windows after its driver installation.

Windows says it protected my PC. Is Amber Studio safe?

Windows shows that screen for new apps that not many people have downloaded yet. It does not mean something is wrong. Only download Amber Studio from the link on this page. To open it, click More info, then Run anyway. If you want to be sure first, right-click Amber Studio.exe and scan it with Windows Security, or upload it to virustotal.com.

Does the demo download anything?

No. The demo uses sample songs and videos. Nothing is fetched from YouTube or saved to your device. Player and remote actions are simulated; the Windows app provides real playback and downloads.

Is it okay to save any video?

Save only what you have the right to keep. Amber Studio is for personal use, and copying YouTube content may breach YouTube's Terms of Service.
